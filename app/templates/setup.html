Google doesn't offer a shared sign-in like Microsoft's — every self-hosted instance needs its own free Google Cloud OAuth app (same pattern Nextcloud, Immich, etc. use). About 10 minutes, one time. Show the steps

  1. Go to console.cloud.google.com and create a project (any name).
  2. APIs & Services → Library → search Google Tasks API → Enable.
  3. Google Auth Platform (left sidebar) → Get started → App name "TaskBridge" + your email as support email → Audience External → add your own Google account under test users → your email again for contact → agree & create.
  4. Data Access (left sidebar) → Add or remove scopes → filter for "tasks" → check .../auth/tasks ("Create, edit, organize, and delete all your tasks") → Update → Save.
    Don't skip this — without it, signing in still appears to work but every actual sync call fails with a 403.
  5. Clients (left sidebar) → Create client → Application type Web application.
  6. Under Authorized redirect URIs, add exactly:
    {{ google_redirect_uri }}
    Google requires this to be http://localhost:<port>/… or a real domain with a public suffix (e.g. .com, .org) — a bare LAN IP like http://192.168.1.50:3737/… is rejected. If that's how you reach TaskBridge (most home servers), give it a real hostname first — a free DuckDNS domain pointed at that IP, or (behind a reverse proxy, Umbrel included) a Tailscale MagicDNS address with HTTPS enabled — then use that instead.
  7. Create it, then copy the Client ID and Client secret into the form below — and set TaskBridge's address to that exact same hostname.
